치지직 데스크톱 앱

Windows·macOS 에서 방송 목록을 보고 녹화방송·라이브를 시청하는 앱입니다. 로그인·방송 등록·송출·후원은 앱의 "웹에서 열기"로 브라우저에서 합니다.

Windows

Windows 10·11, x64 (ARM64 PC 는 x64 에뮬레이션으로 실행)

    설치·실행

    1. 설치 파일(.exe)을 내려받아 실행 → 설치 위치 선택 → 완료하면 시작 메뉴·바탕화면에 "치지직"이 생깁니다.
    2. 또는 무설치(.zip)를 풀고 Chzzk.exe 를 실행합니다.
    3. 서명하지 않은 앱이라 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.

    macOS

    macOS 12 이상, Apple Silicon(arm64) · Intel(x64) 각각 제공

      설치·실행

      1. 내 Mac 에 맞는 .dmg 를 열고 "치지직"을 응용 프로그램 폴더로 끌어 놓습니다. ( Apple 메뉴 → 이 Mac에 관하여 에서 칩이 Apple M… 이면 Apple Silicon, Intel 이면 Intel )
      2. 서명하지 않은 앱이라 처음에는 응용 프로그램 폴더에서 앱을 우클릭 → 열기 → 열기로 실행합니다.
      3. "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 xattr -dr com.apple.quarantine /Applications/Chzzk.app 후 다시 엽니다.

      앱에서 확인하기

      1. 앱을 열면 이 서비스(배포 주소)의 방송 목록(라이브 방송·녹화방송)이 보입니다.
      2. 녹화방송을 누르면 바로 재생되고, ● 방송 중인 라이브를 누르면 실시간 시청이 시작됩니다.
      3. 다른 서버에 연결하려면 앱 오른쪽 위 설정에서 서버 주소를 바꿉니다.
